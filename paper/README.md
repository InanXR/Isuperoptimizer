# The Paper

**A Certificate-First x86-64 Superoptimizer with a Calibrated
Comparison Against GCC** — the system written up as a systems paper.

## Build (regenerates from the live artifacts)

```sh
./build.sh              # add --preview for PNG page images
```

The build is the paper's claim made executable, in order:

1. **re-checks every committed artifact** with `recheck` (all nine
   JSONL files of record, live; any FAILED aborts the build);
2. **re-runs the claims audit** (`tools/audit_claims.py`, from the repo
   root; 485 checks; any mismatch aborts the build);
3. **verifies the bibliography provenance** (`check_bib.py` against
   `bib-sources.json`): every `\bibitem` must be a confirmed,
   evidence-linked publication; unconfirmed candidates are flagged and
   abort the build;
4. **extracts every number in the paper** with `extract_data.py` into
   `generated/` (55 macros, three table bodies, six assembly listings,
   two chart coordinate sets, and the recheck/audit outputs this build
   just produced; untraceable values abort the build);
5. **compiles** `paper.tex` (IEEEtran + Libertinus, pdflatex via
   latexmk when available);
6. **runs the house-style gate** on the rendered PDF
   (`check_style.py`): no em dashes, and none of the banned stock
   constructions ("is not just", "not only", "but rather", ...);
   any match aborts the build.

## Typography

One five-colour palette (ink, accent green, steel blue, neutral gray,
ochre) drives every figure, diagram, and table rule; Libertinus Serif
carries the body and mathematics, Libertinus Sans the headings and
chart labels; section headings are styled with a rule under the title,
and running headers plus footers carry the title and page number.
Tables use booktabs with numeric columns right-aligned.

## Why IEEEtran

`acmart` is the class of the venues this work cites (ASPLOS-style), but
IEEEtran was chosen deliberately: it is the most robust offline
two-column systems-paper class in TeX Live (`texlive-publishers`), its
float rules handle the wide `table*`/`figure*` content this paper
carries (23-row results table, 23-bar outcome chart) gracefully, its
`\IEEEpubid` gives the requested author/footer block, and its caption
and bibliography conventions need no extra packages to look right.
pdflatex (not xelatex) is used because the source is ASCII-clean and
the toolchain is the lightest.

## Layout

- `paper.tex` — the document
- `extract_data.py` — the traceability extractor (the only source of
  numbers)
- `check_bib.py` + `bib-sources.json` — bibliography provenance gate
- `check_style.py` — house-style gate on the rendered PDF
- `build.sh` — the pipeline above
- `generated/` — build outputs (regenerated by every build; the
  extraction is deterministic given the artifacts)
- `references` — inline `thebibliography` (45 entries, all verified;
  no BibTeX pass)
